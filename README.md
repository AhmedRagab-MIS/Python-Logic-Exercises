# تدريبات بايثون - المنطق البرمجي 🐍

المستودع ده فيه شغل عملي على أساسيات بايثون.

### 📁 المشاريع:
* **نظام الـ ATM:** سحب وإيداع وتحديث رصيد.
* **نظام التقديرات:** تحويل الدرجات لتقديرات (A, B, C).
  
 ### المشاريع المضافة حديثاً:
* **نظام الآلة الحاسبة المستمرة:** تطبيق للعمليات الحسابية المتكررة دون إغلاق البرنامج.
* **تطبيق قائمة المشتريات** إضافة عناصر للقائمة بشكل ديناميكي وحفظها.
* **لعبة تخمين الرقم:** تحدي تفاعلي يعتمد على الحلقات التكرارية (Loops).
* **نظام إدارة كلمات المرور:** تخزين وإدارة الكلمات بشكل آمن
