# تدريبات بايثون - المنطق البرمجي 🐍

المستودع ده فيه شغل عملي على أساسيات بايثون.

### 📁 المشاريع:
- **نظام الـ ATM:** سحب وإيداع وتحديث رصيد.
- **نظام التقديرات:** تحويل الدرجات لتقديرات (A, B, C)
- 📂 المشاريع المضافة حديثاً:
نظام الآلة الحاسبة المستمرة: تطبيق يسمح للمستخدم بعمل عمليات حسابية متكررة دون إغلاق البرنامج.
تطبيق قائمة المشتريات: برنامج لإضافة عناصر للقائمة بشكل ديناميكي وحفظها.
لعبة تخمين الرقم: تحدي تفاعلي يعتمد على الحلقات التكرارية (Loops) والمنطق البرمجي.
نظام إدارة كلمات المرور: (بما إنه موجود في ملفاتك) برنامج بسيط لتخزين وإدارة كلمات المرور بشكل آمن
